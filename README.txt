IMPORTANT:
- Your existing Google Sites website is not changed.
- The booking form is intentionally in preview/demo mode until the exact Apps Script doPost request format is verified. Do not accept live bookings on this new page yet.

- Some lash prices are shown as indicative ranges; verify them against your current price list before public launch.
- Replace sample editorial images with your own Benisse Studio photos before launch.
- Location links currently use Google Maps searches, not verified exact pins.

Beginner publishing outline:
1. Create a GitHub account or sign in.
2. Create a NEW public repository named benisse-animated-site.
3. Upload index.html to the repository root.
4. Open Settings > Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the published URL to appear in Settings > Pages.
7. Test the site on desktop and mobile. Do not switch your existing website or booking link until the booking integration is verified.

The Apps Script web app URL provided by you is not hard-coded into this preview yet because the expected POST format needs to be confirmed from your current doPost(e) function. This avoids silently breaking bookings.
